# Voice & Tone — Claude Project Package

This package lets you recreate the "Voice & Tone" Claude project — a setup used to review Expert-facing content (headers, scripting, and other copy that guides Asurion call center agents or helps them communicate with customers) against Asurion's Joy brand voice.

**Start here:** open `SETUP-INSTRUCTIONS.md` for the step-by-step walkthrough.

## What's included

- **`project-instructions.md`** — the custom instructions that define Claude's role, what feedback to give, and the output format. Paste this into your new project's Instructions field.
- **`working-conventions.md`** — formatting conventions that developed through use (the feedback-table format, the color-coded issue-tag legend, the headers-vs-verbatim rule, and a note on Notion being the source of truth). Not part of the official brand docs, but worth uploading so feedback looks and behaves the same way.
- **`conversational-ui-patterns.md`** — reference material pulled from a customer-facing Conversational UI Figma file (named interaction patterns + a tone phrase bank). Used to calibrate Expert-facing tone/headers against what's live on web, without copying its structure wholesale.
- **The brand voice source files** — `Core Identity.md`, `Core Identity Final(ish) Draft.md`, `WIP Joy for Experts.md`, `AI Personality Wiki.md`, and `Expert Workspace flow examples.md`. These are the knowledge files the project uses as its source of truth for tone, style, and the Expert persona specifically.

## A note on staying current

`AI Personality Wiki.md` links out to a live Notion workspace that's the maintained, canonical version of this material — the files in this package are a snapshot and can lag behind it. If something here ever seems off or outdated, check Notion first.
